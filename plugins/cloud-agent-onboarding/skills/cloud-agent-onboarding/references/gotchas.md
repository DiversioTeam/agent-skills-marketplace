# Gotchas

Every row was hit for real between 2026-10-13 and 2026-10-17 unless marked
(docs). Grouped by where it bites.

## Platform (Claude Code on the web)

| Symptom | Cause | Fix |
| --- | --- | --- |
| Session fails before the agent starts: "No `pyproject.toml` found" | Setup script ran outside the clone | Install tools only; find the clone and `|| true` if you must |
| Corepack picked pnpm 12.x and crashed | No pin; repo files not present | Pin and activate the exact version in setup |
| Image Node older than the repo's engines | Image ships its own versions | Replace only the `node` binary, checksum-verified |
| A login stopped working days later | Setup result cached about a week | Logins in the SessionStart hook |
| Hook never ran; skill missing | Multi-repo session, or a branch without the skill | Single-repo starts; user-level `~/.claude/CLAUDE.md` fallback plus bootstrap |
| Submodule folders empty; `git -C <dir>` changed the parent | Only attached repos reachable | Hook says "attach with add_repo, rerun"; warn about `git -C` |
| Submodule clone failed with SSH URL | GitHub proxy speaks HTTPS | `url."https://github.com/".insteadOf "git@github.com:"` |
| A tool got `403` from the egress gateway | It ignores `HTTPS_PROXY` | Local relay through the proxy with `CONNECT` |
| Upload broke with 403 / error 8000013 | Network secret overwrote the tool's own `Authorization` | Path-prefix the secret |
| Secret missing in sessions | Clicked **Add** but not **Save changes** | Click both; read back |
| Hosts or path prefixes not saved | Not turned into chips | Press Enter after each |
| Secret wrong | Saved secrets are write-only | Delete and re-add; human pastes again |
| `gh pr create` fails in session | GraphQL blocked (docs) | Connector tools or `gh api repos/...` |
| Commit status write 403 "not permitted through this proxy" | GitHub proxy refuses it for every token | CI posts statuses from a verified commit record |
| GitHub token as network secret did nothing | Network secrets never go to GitHub hosts | Don't; sessions use the GitHub app |
| Session refused to record "approved by <name>" | Session safety check: unverified approval | Record a request; approvals on a signed-in page |
| Change to the environment or settings not seen | Only new sessions get it | Fresh session per test |
| Allow-listed script still asked for approval | Ran after `cd …;` or into a pipe | Run it bare from the repo root |
| Session called an artifact "private" on a shared account | Wrong mental model | "Draft copy, everyone on this account can open it" |
| Branch delete or tag push rejected | GitHub proxy rules (docs) | Do those from an engineer's machine |
| PR body ends with "Generated by Claude Code" | Connector's `create_pull_request` adds it | `update_pull_request` with the clean body, read back |
| Commits carry `Claude-Session:` trailer (docs) | Default attribution | `attribution.sessionUrl` setting if the repo forbids it |
| Agent keeps being told to commit and push | claude.ai end-of-turn check | One-line answer; wait for "save it" |
| Allow-listed script still blocked | Auto mode classifier (acting as a real user, admin grants) | Synthetic users; the person switches to Accept edits for approved cases, then back |
| Tool result "exceeds maximum allowed tokens", spilled to a file | Huge MCP result | Compact results; bulk data behind another tool |
| Report path useless to the person | VM files are not reachable | Publish a private artifact |
| Publish refused | Raw U+FFFD in the page | Escape it |
| Garbled characters ("âœ“") | Page without a charset opened locally | `<meta charset="utf-8">` or entities |
| Stored setup script hash differs | Final newline dropped | Hash without it |
| Playwright in the repo could not download its browser | Download blocked | Use the image's browser, or do not prescribe one |

## Platform (Codex cloud)

| Symptom | Cause | Fix |
| --- | --- | --- |
| "repository authentication for <org>/<repo> failed" | GitHub access for the org (unresolved in our pilot) | Verify cloning in a throwaway task before building |
| Installs work in setup, fail in the task | Agent-phase internet off by default (docs) | Enable the narrowest preset |
| Token gone during the task | Legacy: secrets only during setup (docs) | Use setup for fetching; current flow network secrets |
| `export` in setup lost | Each script runs in its own Bash session (docs, Legacy) | Write to `~/.bashrc` or use environment settings |
| Change to the environment not seen | Current flow needs republish (docs) | Republish, start a new task |
| Old docs links | Moved to learn.chatgpt.com | Use the new URLs |

## Outside systems

| Symptom | Cause | Fix |
| --- | --- | --- |
| Token printed in the agent's output | CLI prints plain text; error branch echoed it | Mint into a variable, pipe to the vault, print length + hash; revoke and record any leak |
| Signed-out CLI reported as signed in | Status command exits 0 either way | Grep output |
| CLI broke after "pinning" it | Server rejects old CLIs | Allow self-update |
| Each login added an SSH key | CLI registers a key per login | Prune keys now and then |
| Multi-line remote command broke | Transport cannot carry newlines | Base64-encode |
| Sync overwrote 74 files | Stale base | Ancestor guard |
| Same workspace name, different repo per template | Template differences | Confirm before syncing |
| Template "show" printed real keys | Secrets in plain template variables | Never print unfiltered; safe summary script |
| `wrangler pages project create` went to Workers | CLI default | `--force` |
| Wrangler refused to start | No token variable | Placeholder variable |
| Two previews overwrote one link | Same alias words | Random suffix |
| Bare preview domain not protected | Wildcard Access app | Add the bare domain |
| Hosting assigned `<name>-<3 chars>.pages.dev` | Name taken | Create the project before writing host names anywhere |
| Access cannot protect the custom domain | DNS not in a Cloudflare zone | Site signs people in itself via an Access SaaS (OIDC) app |
| OIDC `/jwks` HTTP 500 forever | Zero Trust team domain renamed | New SaaS app; test a fresh sign-in after renames |
| Setup script failed 403 creating service tokens | Token not allowed to | Idempotent script skips the step; human creates it |
| Two reader lists disagreed | Copies in the provider and the repo | One source of truth, or a sync check |
| Branch preview could read production secrets | Secret set for Preview | Production-only secrets |
| Real SMS from a test copy | Template wired to a real provider | Default to the no-SMS template |
| A code read-only guard did not stop writes | The secret applies to any request to the host | Read-only token scopes |

## Browser automation and agent hygiene

| Symptom | Cause | Fix |
| --- | --- | --- |
| Port 9222 already in use | Another session's Chrome | Leave it; another port, own profile |
| Remote debugging refused | Default Chrome profile | `--user-data-dir` |
| Closed the tab the user was typing in | Agent closed tabs | Never close tabs; new tabs for sign-ins |
| Environment renamed "…eeed" | Edit dialog opens with focus in Name | Check the name before Save |
| A PAT visible in a check screenshot | Screenshot of a dialog with a pasted value | Never screenshot those; read lengths |
| Stray sign-in email sent | Screenshot tab captured the person's keystrokes | Own tabs only; stop when someone is typing |
| Hover submenu would not open | Synthetic `click()` | Real mouse move, then `ArrowRight` |
| Local agent blocked after "please do it" | Its safety check: access grants, secret writes, merges, release approval | Human clicks; never loosen controls to get past it |
| Turning off branch protection didn't unblock | The block was the safety check | Find what is blocking before loosening a control |
| User's Chrome closed | `browser.close()` over CDP | Exit the process instead |
| Playwright attach hung | Chrome version | Raw CDP client |
| `.value =` ignored | React-controlled field | Native setter + `input` event |
| Checkbox not ticked | Clicked the label | Click `span[role=checkbox]`, read `aria-checked` |
| Menu closed mid-step | Pointer left | Open-hover-click in one call |
| Stale refs in menus | Playwright MCP snapshots | Re-snapshot after each click |
| Composer click timed out | Clicked the placeholder span | Target the contenteditable |
| Overlay intercepted a click | One-time notice | Tolerate missing elements; target inputs by placeholder |
| "Mutation checks" ran nothing | zsh does not word-split `$CMD` | Use a shell function |
| Too many browsers launched | Over-eager automation | One browser, a few small steps at a time |
